# TIDEBREAKER: sketch prompts for the owner

Paste these into your image tool. They are written in plain English, so they work in most image generators.
If your tool has an aspect-ratio setting, pick **16:9**. If it has a "negative prompt" box, paste the negative line.

**How to send them back:**
1. Make 3-4 tries of each **model sheet** and pick the one you like.
2. If your tool can use a reference image, use the picked sheet as the reference for that character's
   **expression sheet**, so it's the same person.
3. Drop the picked images into `assets/characters/tidebreaker/`, named after the character
   (e.g. `rinka_model.png`, `rinka_expressions.png`). PNG or JPG is fine.

I then lock each design: matching drawing tags, reference images, and a test shot in our pipeline so you can
judge the character moving and talking.

**Negative prompt (all characters):**
`text, watermark, logo, signature, labels, weapon, sword, extra fingers, deformed hands, 3d render, photo, realistic, blurry, cropped body, overlapping poses, blending views, shifting hairstyle, changing clothes between views, gradient background, shadows under feet, rough sketch lines`

**Background rule (all sheets):** solid uniform medium grey, no gradient, clean empty space between views and
faces. This keeps the cut-outs clean when the pipeline mattes the character.

**Order:** Rinka first, then Seiran and Hisui. Tomo, Yuzu and Gonta can follow later; Kagari and Raizen (episodes 5-12) last.
